# 🎬 Movie App (React)

TMDB API kullanarak film detaylarını gösteren, fragman izleme imkânı sunan bir web uygulaması.

> **Not:** Bu proje, Türkiye Yazılım Akademisi (Sadık Turan) tarafından hazırlanan
> "Komple Uygulamalı Web Geliştirme Eğitimi" kursu takip edilerek yapılmıştır.
> Öğrenme amaçlıdır.

## ✨ Özellikler
* **Fragman desteği:** Filmlerin fragmanlarını modal içinde izleme
* **Responsive tasarım:** Mobil ve masaüstüne uyumlu detay sayfaları
* **Tema desteği:** Karanlık ve aydınlık mod
* **Watchlist:** İzlenecekler listesi yönetimi

## 🚀 Kullanılan teknolojiler
React, Vite, React Router, axios, Bootstrap, TMDB API

## ⚙️ Çalıştırma
1. Projeyi indirin ve klasöre girin.
2. Bağımlılıkları kurun: `npm install`
3. [TMDB](https://www.themoviedb.org/) üzerinden ücretsiz bir API anahtarı alın.
4. Proje klasöründe `.env` adlı bir dosya oluşturup şunu yazın:
   `VITE_API_KEY=anahtarınız`
5. Uygulamayı başlatın: `npm run dev`
